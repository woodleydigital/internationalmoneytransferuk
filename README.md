# International Money Transfer UK (IMT UK)

Next.js site for **internationalmoneytransfer.uk**: an independent directory of UK money-transfer
providers, compiled automatically from public records and providers’ own statements.

Read [`CLAUDE.md`](CLAUDE.md) and the topical map in
[`docs/IMT_UK_topical_map.xlsx`](docs/IMT_UK_topical_map.xlsx) before changing routes,
templates or copy.

```bash
npm install
npm run dev        # http://localhost:3000
npm test
npm run typecheck
npm run build
```
