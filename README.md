# International Money Transfer UK (IMT UK)

Next.js site for **internationalmoneytransfer.uk**: a directory of every FCA-authorised money
transfer provider, sister site to [Currency Brokers UK](https://www.currencybrokers.uk).

Read [`CLAUDE.md`](CLAUDE.md) and the topical map in
[`docs/IMT_UK_topical_map.xlsx`](docs/IMT_UK_topical_map.xlsx) before changing routes,
templates or copy.

```bash
npm install
npm run dev        # http://localhost:3000
npm test
npm run typecheck
npm run build
```
